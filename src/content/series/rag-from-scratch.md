---
title: "RAG from Scratch"
description: "A series on Retrieval-Augmented Generation, built from first principles with runnable code: chunking, embeddings, the query flow, evaluation, BM25, and advanced retrieval."
---

Every part implements one piece of a RAG pipeline twice: once from scratch with the Python standard library, and once with real libraries. Each worked example has an expected output, so you can check every claim by running the code in [rag-scratch-to-speciality](https://github.com/sesha-2k3/rag-scratch-to-speciality).

Start with Part 0 for setup, or jump to any part that interests you.
